# Visualization Exam 2026

Exam project for the Visualization course (Prof. Bernhard Schmitzer), University of Göttingen, summer term 2026.

## Overview

Two problems analyzing real-world datasets.

**Problem 1: Munich public transport network (MVG)**
Analysis of the Munich GTFS transit data: stops, routes, trips, schedules, temporal distributions, velocity profiles, and an animated weekday simulation.

**Problem 2: German census data 2022**
Analysis of municipality-level census data: population distributions, gender ratios by age, marital status, and PCA on age structure across municipalities.

## Data sources

- MVG GTFS data: https://www.mvg.de/verbindungen/Fahrplandaten.html
- GTFS format reference: https://gtfs.org/documentation/schedule/reference/
